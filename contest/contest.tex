\subsection{Optimization}

\vspace{0.5em}
\begin{itemize}
  \item \verb|optimize("O3")| -- auto-vectorizing, inlining, unrolling loops
  \item \verb|optimize("Ofast")| -- \verb|O3| + some \bf{unsafe} math (beware of it)
  \item \verb|optimize("trapv")| -- debug int overflows (WA becomes RE)
\end{itemize}

Use \verb|__attribute__((target("..."), optimize("...")))| to enable for the function only
