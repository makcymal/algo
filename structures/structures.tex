\subsection{Fenwick Tree}

Zero-indexed.
Segments include end: $[a, b]$.
\verb|tree[0]| isn't used.
\verb|data| is 1B: \verb|tree[i]| keeps \verb|f(data[i - (i & -i) + 1, i])|, \verb|data[i]| is counted in all \verb|i := i + (i & -i)|.
\tc{\log n}
\cppcode{structures/fentree.cpp}

The same, but on the plane.
\complexity{\log n \log m}{nm}
\cppcode{structures/fentree_2d.cpp}

The same, but for maximum. Only increasing value updates allowed.
\tc{\log^2 n}
\cppcode{structures/fentree_max.cpp}
